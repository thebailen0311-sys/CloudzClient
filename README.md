# Cloud Client (Fabric 1.21.11)

Build: `./gradlew build` -> `build/libs/cloudclient-1.0.0.jar`

Old `wtapclient.json` settings are loaded automatically if `cloudclient.json` does not exist yet.

Combat: Aim Assist, Triggerbot, W-Tap, Auto Mace, Shield Breaker, Auto Hit Crystal, Anchor Macro, Auto Totem, Spear Lunge.
Modules with extra binds (Anchor Macro, Spear Lunge) must be enabled; set the binds inside their settings (right-click a bind to clear).
